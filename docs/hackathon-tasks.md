# ثلاجتي — مسودات مهام هاكاثون نمكّن (غير رسمية)

نصوص جاهزة للصق/النقاش. التسليم اليومي اختياري؛ المشروع النهائي هو الإلزامي.

---

## المهمة 1 — الفكرة

**المشكلة:** كل يوم يتكرر سؤال «وش نطبخ؟» — نفتح الثلاجة، نتردد، نكرّر نفس الأكل، أو نشتري وننسى اللي عندنا.

**لمن؟** من يدير طبخ البيت يوميًا ويبغى قرارًا سريعًا + قائمة للناقص.

**الفكرة بجملة:** تطبيق عربي «ثلاجتي» يحوّل محتويات الثلاجة (أو اقتراحًا عشوائيًا) إلى وصفات جاهزة، ويخلّي وصفاتك الشخصية جزءًا من نفس قرار الطبخ — بدون حساب وبدون تعقيد.

**ليش حقيقية؟** المشكلة يومية؛ القرار يبطّل؛ والحل يوفّر وقتًا ويقلل الهدر ويجعل الاقتراحات أقرب لمطبخك الفعلي.

---

## المهمة 2 — الـ MVP (شاشات أولية)

أربع قدرات قرار (التسوق جزء من النتائج):

1. من الثلاجة → وصفات مطابقة  
2. عشوائي لبكرة بدون تكرار ممل  
3. قائمة شراء للناقص  
4. أضيفي وصفتي → تغذي الكتالوج (Supabase)

**شاشات للـ PDF / الـ wireframe:**

1. الرئيسية — مساران قرار + رابط إضافة وصفة  
2. الثلاجة — أشخاص / ممنوعات / مكونات  
3. النتائج — بطاقة + فلاتر + شراء  
4. العشوائي — طبق + «غيرها»  
5. إضافة وصفة — اسم + chips مكونات + حفظ  

الرئيسية تبقى قرار أولًا؛ الإضافة مسار ثانوي يEnrich المحرك.

## المهمة 3 — دليل الهوية + بروتوتايب

نفس هوية ثلاجتي (أخضر ورقي، زعفران، Cairo + IBM Plex Sans Arabic، أيقونة الثلاجة).

| خطوة | ثلاجتي |
|------|--------|
| الفكرة | قرار أكل البيت من اللي عندك + وصفاتك |
| MVP | ثلاجة / عشوائي / شراء / إضافة وصفة |
| قصة العلامة | وضوح وهدوء؛ قرار سريع من المطبخ الحقيقي |
| لوحة إلهام | ثلاجة مفتوحة، أطباق بيتية دافئة، أخضر + زعفران |
| الألوان | `#f3f6f1` خلفية، `#1a2e22` حبر، `#2f6f4e` ورق، `#e0b84a` زعفران |
| الخطوط | Cairo عناوين · IBM Plex Sans Arabic نص |
| الشعار | «ثلاجتي» + أيقونة ثلاجة بسيطة |
| عناصر الواجهة | زر قرار رئيسي، chips، بطاقة وصفة؛ نموذج الإضافة بنفس اللغة البصرية |

**البروتوتايب:** رابط التطبيق المستضاف (أو Figma) يمرّ على الشاشات الخمس أعلاه، بما فيها `add-recipe.html`.
